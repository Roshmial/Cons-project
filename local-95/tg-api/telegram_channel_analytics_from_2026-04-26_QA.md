# QA первого отчёта по Telegram-каналам

Проверка выполнена по raw export и файлу первого отчёта.

## Что соответствует запросу

- Разовая выгрузка действительно сделана без `since`: это зафиксировано в отчёте и подтверждается наличием raw export.
- Общие количества по каналам в первом отчёте совпадают с raw export.
- Пустые/media-only сообщения отдельно оговорены и не включены в содержательную классификацию.
- По каждому каналу есть базовые блоки: аудитория, темы, исследования, мероприятия, услуги, проекты, партнерства.

## Где качество недостаточное

- В части каналов после первых крупных разделов слишком сильная агрегация: перечислены темы/проекты без ссылок на конкретные посты.
- Нет полного реестра непустых сообщений, поэтому часть исходных данных теряется для пользователя.
- Для каналов `k2_tech`, `Lanit_life`, `InnotechCompany`, `YakovPartners`, `delret`, `tedo_business`, `kept_business`, `Reksoft_group`, `norbit_ru` в первом отчёте практически нет ссылочной доказательной базы внутри пунктов, хотя raw export содержит `original_url` для всех сообщений.
- Блоки «ключевые темы» ограничены и сжаты; это удобно для executive summary, но плохо для задачи “не терять данные”.
- Некоторые формулировки выглядят как интерпретации без явного указания постов-оснований. Их нужно либо снабжать ссылками, либо переносить в отдельный блок “интерпретация”.
