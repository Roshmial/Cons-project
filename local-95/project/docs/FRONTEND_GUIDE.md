# Инструкция по работе с frontend

## 1. Вход

Открыть в браузере:
`http://127.0.0.1:8793`

Для demo-входа использовать:
- `misha@demo.local / demo123`
- `admin@demo.local / demo123`

## 2. Основные зоны интерфейса

Во frontend есть четыре ключевых зоны:
- блок логина и текущей сессии;
- список чатов;
- окно активного диалога;
- профиль и admin-инструменты.

## 3. Работа с чатами

Пользователь может:
- открыть существующий чат;
- создать новый чат;
- переименовать чат;
- архивировать чат;
- включить просмотр архива;
- вернуть чат из архива.

Логика важная:
- frontend не хранит каноническую историю сам;
- после каждого действия он опирается на backend API;
- backend остаётся владельцем app-state.

## 4. Отправка сообщений

Как работает отправка:
1. пользователь пишет сообщение;
2. frontend отправляет его в backend;
3. backend вызывает Hermes API Server;
4. frontend получает уже готовый assistant response.

Если ответ не приходит, первым делом нужно проверять:
- доступность backend;
- доступность Hermes API Server;
- валидность сессии пользователя.

## 5. Профиль пользователя

Во frontend можно редактировать профиль:
- имя;
- таймзона;
- язык;
- команда;
- роль;
- цели;
- стиль ответа;
- ограничения;
- pinned notes.

После сохранения backend пересобирает personalization block.

Практический смысл:
- изменения профиля должны влиять на будущие ответы Hermes;
- сам frontend только показывает и отправляет изменения, но не интерпретирует их.

## 6. Feedback

Для assistant messages можно отправлять feedback:
- useful / not useful;
- reason codes;
- комментарий.

Это используется как app-level feedback и сохраняется в backend.

## 7. Admin-режим

Для admin-пользователя доступны дополнительные экраны:
- health;
- users;
- threads;
- events.

Это не отдельный backend. Это тот же frontend, который показывает admin endpoints на основе роли пользователя.

## 8. Что делать при типовых сбоях

### Если страница открывается, но login не работает
Проверить:
- работает ли backend на `127.0.0.1:8791`;
- не истёк ли token;
- нет ли ошибки CORS.

### Если login работает, но ответы не приходят
Проверить:
- backend health;
- `mode` backend;
- доступность Hermes API Server на `127.0.0.1:8642`.

### Если пропали чаты или профиль
Проверить:
- SQLite backend;
- не был ли пересоздан data-файл;
- не запущен ли другой backend с другим `data` каталогом.
